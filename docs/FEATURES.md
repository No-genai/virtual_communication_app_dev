## 完了していない主要項目

1. 実際のMac同士・別回線での通話到達、画面共有、デバイス切替の確認。
2. 10〜30人が必要なカメラ台数・画面共有数で同時利用する負荷試験。
3. 公開HTTPSとTURN。全員映像ONや安定した配信が必要ならLiveKit等のSFU統合。
4. 公式仕様の確認に基づく追加機能の確定。
5. 登録アカウント、永続的なBAN、役割委譲、録画、SSO等は未実装。これらを必要とする運用には追加開発が必要。

単にボタンを表示しただけの機能を完成とは扱っていません。通話の受信検証が失敗しているため、イベント本番の準備完了とはしていません。

共通マップ内の村は会話を分けるための部屋です。アバターは全村に表示され、掲示板・描画・投票・主催者管理はスペース全体で共通です。独立した認証・データ保管が必要な場合は、別のスペースを作成してください。

### アバターのアクション

ハート・手振り・拍手・ダンス（5秒間）、挙手ポーズ、走行、最大3人の馬車を追加。移動モードは再選択で解除できます。相乗りは招待・承諾方式。自動巡回、村限定アクションは未実装です。

### 画面配置とショートカット

基本画面を表示領域に合わせて配置。数字1〜7と0でアクションを操作できます（マップにフォーカスがある場合のみ）。スマホではチャット・参加者を切替表示。クリック用アクションはメニューにまとめています。

### 0.9の遊び機能

ペット3種、帽子・服・小物の着せ替えとローカル保存、招待式の相乗り（3人まで）、天気・時間・四季、日付入りPNG記念写真を追加。景色は個人プレビューと主催者の共有設定があり、共有設定のみサーバーに保存します。

### 0.10の表示

初期表示を晴れ・昼・春に変更。夜の暗幕を弱め、マップを拡大。詳細な通話操作と映像は「通話設定」パネルから開きます。

### 0.11の交流・学習機能

話題の焚き火（固定8題、輪の中の会話）、交流の目印、都会の村で一般基礎クイズ（14問から6問、解説・誤答復習）を追加。スパルタ塾の全教材準拠コースは教材の提供待ちで未実装です。成績の保存・先生用の成績管理・自動問題生成は未実装です。

### 0.12 GitHubの使い方
- 6章の説明と自分のForkを使う練習手順、章別2問・まとめ6問、回答解説と復習リンク。
- 読了の自己チェックをブラウザに保存。GitHubとの自動連携や実作業の自動採点は含みません。
