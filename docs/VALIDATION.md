## 残る検証

管理ポリシー `WebRtcIPHandling=disable_non_proxied_udp` が適用されたクラウドのブラウザでは、ローカルTURN/TCPを使ってもICE接続が成立しませんでした。管理ポリシーは変更していません。メディアE2Eは削除/無効化しておらず、`npm run test:media` または全件の `npm run test:e2e` で受信まで検証します。

本番に使うMac・回線・TURN環境でのメディアテスト、必要なカメラ台数での10〜30人の負荷試験、公開HTTPS環境での確認が必要です。「イベント本番の準備完了」「MetaLifeと全機能同等」とは判定していません。
