## 取り込み時に区別・補正する点

模擬ターミナルはJavaScriptの仮想ファイルシステムで動き、実LinuxやSSH接続ではありません。説明カードに載っていても、操作が完全には実装されていないものがあります。静的コード確認で次を確認しました。

- resolvePath（script.js:768付近）は/をホーム相当として扱う簡略化があり、実Linuxの/と~の違いの採点にはそのまま使えません。
- doMkdir（1197付近）はmkdir -p a/bを階層として作成せず、スラッシュを含む名前として扱います。
- doRm（1233付近）は-iの確認処理がなく、doCp（1253付近）は-rなしのディレクトリ複製も許します。説明カードと実装が一致しません。
- echoのリダイレクト（980付近）は出力文字列にリダイレクト部分が残る作りです。sort -n等、教材に掲載されたオプションの一部も模擬実行では未対応です。
- chmod/chown/sudo/SSH等には成功メッセージや説明を表示するだけの処理があります。模擬実行の表示を実技の正解判定に流用しません。
- SSH初回接続のヒントはyes入力を促すだけです。問題化する際はホスト鍵のフィンガープリントを信頼できる情報と照合する説明を補います。
- touchの既存ファイル操作やwcのバイト数、Permission deniedの原因などは実環境の意味を確認して、単純化しすぎた説明を補います。
- ファイル名や一部の引数をinnerHTMLへエスケープせず入れる箇所があります（doLsなど）。模擬ターミナルを移植する場合は別途修正と動作検証が必要です。今回はソースを実行・移植していません。

## 村の学習機能への反映案

Linux道場の39コマンド全体を7章へ整理し、意味だけでなくオプション、出力予想、場面に合う操作、注意点を問う問題にします。各問題には参照コマンド・元ファイルの該当箇所を紐付け、章別テスト、全範囲の確認、誤答の再学習を提供します。6問だけのランダムテストでは全範囲をカバーしたことにならないため、項目ごとの出題・正答履歴も必要です。
